## Quick Start

### New Contributors
1. **Read [THE_FIVE_LAWS.md](./THE_FIVE_LAWS.md) first** - These are the supreme engineering principles
2. Read [ARCHITECTURE_CONSTITUTION.md](./ARCHITECTURE_CONSTITUTION.md) for project overview
3. Review [CODING_STANDARDS.md](./CODING_STANDARDS.md) for code guidelines
4. Check [DEVELOPMENT_ROADMAP.md](./DEVELOPMENT_ROADMAP.md) for current priorities

### Code Contributors
1. Pick a task from the roadmap
2. Follow the Git workflow in [GIT_WORKFLOW.md](./GIT_WORKFLOW.md)
3. Use the review checklist before submitting PR

### Performance Work
1. Study [PERFORMANCE_HANDBOOK.md](./PERFORMANCE_HANDBOOK.md)
2. Run benchmarks per [BENCHMARK_ELO_TESTING.md](./BENCHMARK_ELO_TESTING.md)
3. Document results in commit messages

## Version Compatibility

These documents are written for NeuralYamame v0.4+ with:
- NNUE evaluation (256 hidden neurons)
- 16M entry transposition table
- PVS search with LMR
- TypeScript/JavaScript implementation

## Contributing to Documentation

When updating documentation:
1. Keep examples working and tested
2. Update version numbers where applicable
3. Maintain consistent terminology
4. Link related documents
5. Add changelog entries for significant changes
